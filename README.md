# ELDORIA

Версия **0.4.0** — визуальный этап Roblox Action RPG по [исходному ТЗ](docs/ELDORIA_SPEC.txt).
Код записан в проект, но **не запускался в Roblox Studio** и не готов к релизу.

Реализован единый игровой цикл: святилище → поручение Иара → бой в роще → награда → три печати →
Хранитель → финал главы. По пути доступны тайники, торговля и улучшение клинка.

- Сервер определяет цели, дистанцию, видимость, урон, затраты, награды и состояние задания.
- Три руны: огонь (урон), лёд (замедление), буря (цепной урон по соседним врагам).
- Комбо из трёх ударов, блок, уклонение, восстановление ресурсов, смерть/возрождение.
- Пять стражей и босс с усиленной второй фазой, предупреждением атаки и возрождением.
- Прогрессия до 200 уровня, улучшение клинка до +5, ограниченные стопки осколков.
- DataStore с арендой сессии, повторными попытками и остановкой игры при сбое записи.
- Русский HUD, меню, рюкзак и экранные боевые кнопки для сенсорного ввода.

## Скачать готовый файл

На странице GitHub нажмите **Code → Download ZIP**, распакуйте архив и откройте
`ELDORIA.rbxlx` из корня проекта в Roblox Studio через File → Open from File.
Это сборка первого этапа, а не проверенный релиз.

## Проверки и сборка (Linux x86_64)

Нужны Bash, curl, Python 3, sha256sum; игровые зависимости отсутствуют.

```bash
cd /workspace/game-roblox
bash scripts/setup.sh
bash scripts/check.sh
```

Установщик загружает Luau 0.726 и Rojo 7.6.1 из официальных GitHub Releases,
с проверкой TLS и закреплённых SHA-256. Повторный запуск использует проверенные архивы.
Результат: `build/ELDORIA.rbxlx`. Это открываемый place-файл, не только модель.

**Быстрый запуск:** скачайте `build/ELDORIA.rbxlx`, откройте в Roblox Studio через
File → Open from File и нажмите Play. Объекты мира и GUI создаются при запуске.
Файл открывайте как отдельное тестовое место; не импортируйте поверх существующей игры.

Для постоянной разработки установите официальный Rojo-плагин в Studio,
запустите `tools/rojo/rojo serve default.project.json` и подключите плагин.
В этой облачной среде прямого подключения Studio нет; сборка файла его не требует.
Подробные пути объектов, настройки сохранения и сценарии проверки: [STUDIO.md](docs/STUDIO.md).

## Управление

WASD — движение, ЛКМ — клинок, E — выбранная магия, Q — следующая руна,
R — уклонение вперёд, F — включить/выключить блок, I — рюкзак.
На телефоне используйте штатный джойстик Roblox и нижние кнопки HUD.
Магия на ПК направлена к курсору; на телефоне выбирает ближайшего врага впереди.
В пределах 48 studs от святилища атаки запрещены, урон игрокам не проходит.
У NPC/кузницы/лавки используйте встроенную подсказку взаимодействия.

## Магия 0.4.0

[Девять заклинаний](docs/SPELLS.md): снаряды с серверным полётом, метеор, кольца,
ледяная волна, цепная молния, вихрь и поток. Анимированы подготовка позы и эффекты.
Q — стихия, 1/2/3 или Z — выбор, E — применение, R — отмена/уклонение.

## Первая локация 0.3.0

[Долина первой зари](docs/FIRST_LOCATION.md): обучение, три стихийные печати,
Хранитель, финальная награда, два тайника, восстановление и карта (M).
Огонь, лёд и буря получили разные эффекты. Контентный маршрут завершён;
приёмка в Studio и замеры ещё нужны. [Референсы и доступ к источникам](docs/DESIGN_REFERENCES.md).

## Визуальное обновление 0.2.0

Добавлены составные анимированные враги, NPC, клинок игрока с замахом/следом,
магические эффекты и числа урона, дальние заклинатели, дома, фонари, лес и руины.
[Описание, пути объектов и проверки](docs/VISUAL_UPDATE.md). Это собственная
процедурная стилизация; сторонние модели и анимационные клипы не импортированы.
При Play номер версии виден в HUD — так можно отличить новый файл от старого.

## Ограничения этапа

Мир и NPC используют составные процедурные модели; финальные модели, анимации,
звуки и вымышленные asset ID не добавлялись. Игроки используют стандартного аватара Roblox.
Баланс, движение NPC, интерфейс на устройствах и сетевой режим требуют Studio-проверки.
Многорегиональный мир, расширенный крафт и экипировка, таланты, конструктор заклинаний,
карта, настройки, цепочка сюжета и социальные системы ещё не реализованы:
[план следующих этапов](docs/ROADMAP.md).
