# Установка и проверка в Roblox Studio

## Структура Explorer

Rojo автоматически создаёт следующие объекты. Других ручных Script/RemoteEvent не нужно.

| Исходник | Путь Explorer | Класс | Назначение |
|---|---|---|---|
| src/shared/Config.luau | ReplicatedStorage/Eldoria/Config | ModuleScript | Баланс боя, магии, врагов, сохранения |
| src/shared/Rules.luau | ReplicatedStorage/Eldoria/Rules | ModuleScript | Схема профиля, уровни, задание, экономика |
| src/server/Main.server.luau | ServerScriptService/Eldoria/Main | Script | Загрузка игрока, remotes, бой, ресурсы, завершение |
| src/server/Profiles.luau | ServerScriptService/Eldoria/Profiles | ModuleScript | DataStore, аренда сессии, сохранение |
| src/server/World.luau | ServerScriptService/Eldoria/World | ModuleScript | Мир, NPC взаимодействия, подписи |
| src/server/Enemies.luau | ServerScriptService/Eldoria/Enemies | ModuleScript | AI, PathfindingService, атаки, участие в наградах |
| src/client/Main.client.luau | StarterPlayer/StarterPlayerScripts/Eldoria/Main | LocalScript | HUD, меню, клавиатура и кнопки |

Main создаёт ReplicatedStorage/Eldoria/Remotes/{Action, State, Notice} (RemoteEvent).
World создаёт Workspace/EldoriaWorld; клиент — PlayerGui/EldoriaHUD.
Config использует Color3, а Rules не зависит от Roblox API. Серверные модули требуют
ReplicatedStorage/Eldoria; их запуск вне Roblox не поддерживается, кроме тестового адаптера Profiles.

## Прогресс и разрешения

1. По умолчанию в Studio профили временные. Это явно указано в рюкзаке.
   Для обычной проверки включать HTTP Requests или API Services не нужно.
2. Сохранение проверяйте **в отдельной тестовой universe**, а не в рабочей игре.
   Опубликуйте тестовый place в неё, включите Game Settings → Security → Enable Studio
   Access to API Services. На ModuleScript `ServerScriptService/Eldoria/Profiles` добавьте
   Boolean attribute `EnableStudioSaving = true`. В live-серверах сохранение включено автоматически.
3. DataStore: `Eldoria_v1`, ключ `player_<UserId>`, формат `{data, owner, lease}`.
   Сохранение каждые 50 секунд, при выходе и закрытии сервера; аренда 180 секунд.
   Не удаляйте lock ради входа: после аварийного завершения дождитесь истечения аренды.
4. Ошибка/неизвестная версия данных блокирует вход, а не создаёт пустой профиль.
   Неизвестные версии намеренно не мигрируются автоматически; перед будущими миграциями
   нужны резервная копия и отдельная процедура. Профиль v1 хранит общий XP (уровень вычисляется),
   золото, осколки, уровень клинка, руну и состояние задания.
5. Ошибка сохранения или утрата владельца сессии отключает игрока. Аренда при этом может
   оставаться до 180 секунд. Три повторные попытки не гарантируют сохранение при полном отказе Roblox.

## Обязательные ручные проверки (пока НЕ выполнены)

1. Откройте сборку как новое место. Play: меню, ввод, HUD, спавн; Output без ошибок.
2. Примите задание у Иара (фиолетовый объект). Победы до принятия не должны засчитываться.
3. Идите по тропе за безопасную зону. ЛКМ: три удара комбо. E: мана расходуется,
   Q: огонь → лёд → буря. Лёд замедляет; буря задевает соседних врагов.
4. Проверьте стены/деревья: атака не проходит через препятствие, NPC перестраивает путь.
   При невозможном пути NPC должен ждать/повторять поиск без ошибок и спама.
5. R уклоняется вперёд, не сквозь стену. F уменьшает входящий урон с расходом
   выносливости. Недостаток ресурсов или cooldown должны блокировать повторное действие.
6. Победите трёх врагов, вернитесь к Иару: ровно одна награда. Продайте осколок в лавке,
   улучшите клинок у кузницы. Недостаток материалов не должен списывать золото.
7. Босс у разлома показывает область за 0.8 секунды до удара. Выйдите из неё, затем
   проверьте урон внутри и усиление частоты/радиуса при HP ниже половины. После смерти
   босс возвращается через 60 секунд, стражи — через 18. Награды получают живые участники
   с попаданием за последние 20 секунд и расстоянием до места спавна менее 100 studs.
8. Умрите, возродитесь: ресурсы и блок сброшены, профиль/задание сохраняются в сессии.
9. Server & Clients (2 игрока): независимые профили, совместное участие в бою,
   единственная награда каждому за убийство. PvP в этом этапе отсутствует.
10. В тестовой universe: получите золото, выйдите/войдите; проверьте rune, XP,
    клинок и задание. Быстрое переключение серверов не должно допускать две активные сессии.
11. Device Emulator: телефон в альбомной и портретной ориентации. Кнопки должны работать
    и не мешать штатному джойстику; проверьте фактическую читаемость текста и размеры касаний.

## Безопасность и оставшиеся риски

Сервер проверяет whitelist действия/руны, тип и конечность вектора, cooldown,
ресурсы, жизнь, дистанцию, видимость, близость к NPC и участие в бою. RemoteEvent
ограничен bucket 12 запросов с восстановлением 8/с; входящие данные не назначают награды.
Экономические операции не yield, повторная выдача награды задания запрещена состоянием.
При этом позиция аватара использует стандартное сетевое владение Roblox: отдельная
защита от speed/teleport exploit ещё не реализована. Нужны adversarial тесты до публикации.
Уклонение проверяет центральный ray, но не полный объём персонажа: углы/узкие проходы
обязательно проверить в Studio. Эффекты создаются сервером и удаляются Debris; нагрузка
тоже требует измерения. Pathfinding ограничен одним запросом на NPC раз в 2 секунды.

Автоматические проверки проверяют правила и логику адаптера, **не** поведение движка,
реальные лимиты/конфликты DataStore, replication, физику или устройства.

## Публикация

До выполнения ручного списка оставляйте доступ приватным. После тестов: отдельная
резервная версия place, проверка разрешений всех будущих assets, затем Publish to Roblox
в нужную universe и повторная проверка реальных входов/сохранения. Публикация не выполнялась.
