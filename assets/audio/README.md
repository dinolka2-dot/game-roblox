# Original ELDORIA sound effects

Eight synthetic mono PCM WAVs, 22050 Hz, generated by scripts/make_audio.py.
No third-party samples. These files may be used and modified as part of ELDORIA.

Roblox cannot play files from a GitHub checkout directly. In Studio, import WAVs
through Asset Manager as the owner/group of the experience. Wait for processing,
then put the resulting numeric IDs in ReplicatedStorage/Eldoria/Config.AudioIds:

```lua
AudioIds = {
    sword = YOUR_UPLOADED_ID,
    hit = YOUR_UPLOADED_ID,
    fire = YOUR_UPLOADED_ID,
    frost = YOUR_UPLOADED_ID,
    storm = YOUR_UPLOADED_ID,
    parry = YOUR_UPLOADED_ID,
    ritual = YOUR_UPLOADED_ID,
    death = YOUR_UPLOADED_ID,
},
```

Replace each placeholder with its actual number; this is a configuration example,
not executable configuration. For Rojo, change src/shared/Config.luau and rebuild.
The Audio client plays uploaded IDs on accepted server events. Empty AudioIds means
sound remains disabled. Uploads and audible playback have not been tested here.
The effects are raw synthetic source material, not a mastered soundtrack.
